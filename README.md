This is my personal portfolio website that I built to showcase who I am as a developer — my skills, the projects I've worked on, and a way for people to get in touch with me. Think of it as my digital resume that actually looks good.

Why I built it:
Instead of sending a plain PDF resume, I wanted something live and interactive that represents my work properly. This project helped me practice frontend development and understand how to structure a professional web presence.

Tech Stack:
Frontend: HTML, CSS, JavaScript (React.js)
Backend: Node.js (used for the contact form and email notifications)
Database: MongoDB / MySQL (optional — for storing contact messages)

What's inside:
*.A fully interactive resume section with my skills and experience
*.A projects section where I display my work with descriptions and links
*.A working contact form that sends email notifications when someone reaches out
